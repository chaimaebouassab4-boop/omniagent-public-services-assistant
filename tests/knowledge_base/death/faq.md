# FAQ - مستخرج شهادة الوفاة

<!-- Compatibility mirror. Canonical structured content: death_certificate_extract.json -->

**محدث: مارس 2026**

1. **كم الأجل للتصريح بالوفاة؟**  
   30 يوماً من تاريخ الوفاة.

2. **من يقدر يصرح بالوفاة؟**  
   الولد، الزوج/الزوجة، الأب/الأم، الأخ، الجد، أو السلطة المحلية إلا تعذر.

3. **شنو الوثائق الرئيسية؟**  
   شهادة معاينة الوفاة + دفتر العائلي أو عقد ازدياد + CNIE للمتوفى والمصرح.

4. **هل مجانية؟**  
   غالباً مجانية أو برسوم رمزية جداً.

5. **فين نروح؟**  
   مكتب الحالة المدنية لمكان وقوع الوفاة أو السكن.
